## Base44 dev setup

- Next.js 16 (Turbopack) app. Dev server: `docker compose -f docker-compose.base44.yml up -d`. Web entry on host port 3000.
- Dependencies installed on container startup via `npm install` (lockfile: `package-lock.json`). Source is bind-mounted; edits hot-reload.
- `next.config.mjs` sets `allowedDevOrigins` from `BASE44_PUBLIC_HOST_SUFFIX` so the preview origin can load dev assets/HMR.
- Optional feature secrets (PDF.co, Google Indexing) are read only at request time in `app/api/*` routes — the app boots without them. Wired via `env_file: /run/base44/app.env`.
- Sitemap is generated by `app/sitemap.js` (Next.js metadata route); bank URLs come from `data/banks.json` (~812 entries).
- Note: Next.js serializes priority `1.0` as `<priority>1</priority>` in the XML (JS `1.0 === 1`); both are valid and equivalent per the sitemap protocol.
